## 🧠 Architecture

- The Kanban board is built as a modular, scalable component system:

- KanbanBoard manages board layout & global controls

- KanbanColumn handles per-column UI & tasks inside

- KanbanCard displays and interacts with individual tasks

- TaskModal manages task create/edit/delete

- Custom HTML5 drag-and-drop logic (no pre-built kanban or DnD libs)

- Key principles followed:

- Accessibility-first (ARIA roles, keyboard support)

- Fully typed (strict TypeScript, no any)

- Tailwind design tokens & modern UI patterns

- High interactivity + component reusability

- State mutation safety + immutability where needed

---

## 🎯 Features

- Drag-and-drop tasks across columns

- Create / edit / delete tasks

- Bulk select & bulk delete

- Quick edit / delete actions on card

- Column WIP limit visual warning

- Search & filter tasks

- Due date picker & overdue indicator

- Fully responsive (desktop/tablet/mobile)

- Keyboard navigation + ARIA + screen reader support
